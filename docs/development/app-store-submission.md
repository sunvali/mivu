# App Store submission checklist

A draft for the owner. Nothing here has been entered in App Store Connect, and no
terms have been accepted. Check each answer against the current form before you
submit.

## Done in the app

- `PrivacyInfo.xcprivacy`: UserDefaults (CA92.1) and disk space (E174.1).
  Photos, health, fitness and user content are declared as collected for app
  functionality, linked to the user and not used for tracking.
- OpenAI sharing consent appears before connecting ChatGPT. A connection saved
  before consent stays unused until the person agrees and reconnects.
- Privacy Policy link and an "estimates, not medical advice" note in Settings.
  The same note appears on the onboarding targets step and in the empty Coach
  screen.
- Onboarding will not set a weight-loss target below BMI 18.5. Pace is at most
  0.75 kg a week, calories never go below 1200, and the minimum age is 13.
- Deleting the last local profile also disconnects ChatGPT.
- iPhone only, portrait only. `ITSAppUsesNonExemptEncryption = NO`: the app uses
  HTTPS, hashing and Keychain only.
- UI-test, sample-mode and connection diagnostic switches exist only in Debug
  builds.

## Notes for Review (draft)

> Mivu is a private food diary. Diary data is stored only on this iPhone. Meal
> capture, editing, history, progress, backup and export all work without an
> account.
>
> Optional AI analysis uses the person's own ChatGPT account. Settings › ChatGPT
> connection › Continue with ChatGPT first shows a consent prompt naming OpenAI
> and the data sent, then opens OpenAI's sign-in. Requests go to the public
> OpenAI API with the person's token, which is stored in the Keychain. Mivu sells
> nothing and has no in-app purchases or purchase links. ChatGPT usage counts
> against the person's own plan.
>
> Test ChatGPT account: <email> / <password>
>
> Nutrition figures are labelled as estimates, not medical advice. Weight-loss
> targets are limited to a healthy BMI and a moderate pace.
