## Crash on Save with unticked work (fixed 2026-11-06)

Found while recording the demo after rebasing on `73b063a0`: saving a gym workout that had an exercise or set never ticked
crashed Mivu (index out of range in `LiveWorkoutView`, then in the superset header). Done keeps only ticked sets in the
store, and the live list under Done redrew against the shorter session. The model now keeps the shown exercises and takes
only the saved copy's identity; the list also skips rows that are gone.

superset (`LiveWorkoutModel.round(of:)` reading a removed row); the iPhone reports at 12:04 came from the earlier build.

gym (ChatGPT only: the on-device model has no workout tools), and continuing a strength workout finished today with the
