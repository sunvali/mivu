# Android end-to-end pass before real-user testing

Recorded 2026-11-06. Why: the owner wants Android smooth and crash-free before the closed test with real users.

- Tested build: the minified release APK (`-Pmivu.testBuildType=release`, debug-signed), built from `main` at `73b063a0`.
  The fixes are in `2129b3de4b72c822a70d583daaee353ec75a4e26` on `fix/android-e2e-findings`; the record's own commit
  changes docs only.
- Environment: macOS 27.0, Android Studio JBR, five read-only instances of `Medium_Phone_API_37.0` (API 37, 1080×2400).
  Not connected to ChatGPT, so no live meal analysis or Coach reply ran.

## What ran

| Run | Scope | Crashes / ANRs |
|---|---|---|
| Monkey, seeds 11–66, 6 × 6,000 events (throttle 120 ms, rotations, app switches) | whole app from a fresh install; reached setup, every tab and Coach sends | 0 / 0 |
| Scripted manual pass, ~60–150 actions each | setup and Today; Diary, meals, manual entry, durability, sharing; Progress, weight, workouts, goals; Coach, camera, voice, history, Settings | 0 / 0 |

Every pass also covered rotation, dark mode, 200% text, Home and reopen, and force-stop and reopen. Saved meals and
weights survived force-stop. Under monkey the app's 50th-percentile frame was 17 ms (gfxinfo; emulator GPU, not a phone).

## Fixed

- Ask Pip on a meal added by hand, on a day without chat, showed "This conversation is unavailable for the current diary".
  It now opens the latest conversation with the meal quoted. Test: `CoachHistoryScreenTest.mealAskPipWithoutChatOpensLatest`
  failed first with that message, then passed. The whole class passed, 12/12, on emulator-5554 with the change (debug build).
  After review the test also checks that the latest conversation loads with nothing highlighted; the class passed 12/12
  again on the commit that adds this line (test and docs only on top of `2129b3de`).
- At 200% text the Progress range control clipped "Month" to "Mont". The labels now shrink to fit. Checked by screenshot
  on the release build at font scale 2.0; no automated test.

## Checked and left as is

- Sharing a photo from the Files app opens Tell Coach with the photo. A share sent from `adb` fails to import because the
  shell grants no read access to the image; that is a test artifact.
- "Adjust total" to 400 saved 399: portions round to two decimals, as on iOS.
- Weights up to 1,500 and very large calorie values are accepted, as on iOS.
- Phone landscape leaves Today a short scrolling area above the pinned Log with Pip / Add manually buttons, as on iOS.

## Open for the owner

- If the app is killed during first-run setup, the next launch opens Today with no targets; setup does not come back
  (iOS shows setup only right after creating a diary, too). Redo setup with Pip in Settings recovers it.
- "Add to this day" is disabled on a past day that has nothing recorded.
