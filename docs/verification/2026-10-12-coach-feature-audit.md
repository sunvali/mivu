# Nutrition and fitness coach feature audit

This source-backed gap matrix maps the owner-approved requirements, to be documented in [the conversational coach design](../superpowers/specs/2026-10-12-conversational-coach-design.md), to the existing English-language native Mivu app. It is grounded in source revision `0e165f47103a8330711d1e19ec39f206e3998d4e`, now merged as `7a86d046200fa4e86e5110b96aa31fd479a99822`, and cites source and named-test evidence inline.

Statuses describe current connected behavior, not a proposed design or live provider acceptance: **Implemented** means the requested behavior exists within the stated scope; **Partially implemented** means a useful foundation exists but the complete owner scenario does not; **Missing** means no connected feature was found; **Needs refactoring** means the existing behavior must change to support the request safely. Test names were found in source; this feature audit did not run them. It does not claim live provider authorization or inference. The requirements exclude diabetes- and celiac-specific functionality. The current direct local route requires no backend; no paid resource or fallback is assumed, and any paid resource requires explicit owner approval.

The current product is an English-only native diary with a synthetic sample analyzer and a separate provider diagnostic. The ChatGPT OAuth/model-catalog path is partially implemented, but live authorization and diary inference were not verified. Preserve local profiles and archive data; exclude diabetes/celiac-specific functionality. The existing local route needs no backend, and this matrix assumes no paid resource or automatic paid fallback.
