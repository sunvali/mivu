# Mivu Widgets Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Home Screen (small, medium), Lock Screen (circular, rectangular) and Control Center widgets that show today's calories eaten of target and open the Log Food camera or Coach.

**Architecture:** The app writes a small `WidgetSnapshot` JSON file into the App Group whenever today's diary changes, then reloads timelines. A new WidgetKit extension reads only that file. Buttons and the control run the existing `LogFoodIntent` and a new `OpenCoachIntent`. Both intents live in a shared folder compiled into both targets, and with `openAppWhenRun` they perform in the app.

**Tech Stack:** Swift 6, SwiftUI, WidgetKit, AppIntents, iOS 26, Swift Testing / XCTest, XcodeBuildMCP.

**Spec:** `docs/superpowers/specs/2026-10-20-widget-design.md`

## Global Constraints

- iOS 26.0 deployment target; Swift 6.0; synchronized folders (`objectVersion = 77`).
- App Group: `group.com.yakov103.mivu`. Extension bundle ID: `com.yakov103.mivu.widgets`.
- Copy: "Log Food", "Coach", "Set a target", "Set up Mivu", "kcal". Kcal numbers rounded to whole numbers with grouping ("1,360 / 2,000 kcal").
- VoiceOver label for the figure: "1,360 of 2,000 calories eaten" / "1,360 calories eaten".
- Calories are **not** `privacySensitive` (owner's call). English only.
- After `rolloverAt` the widget shows `0 / target` (owner's call).
- The extension never opens the diary database, never touches Keychain or credentials.
- Buttons ≥ 44 pt; `containerBackground(for: .widget)`; ring and Pip `widgetAccentable()`.
- Simulator is shared with other agents: claim it only for the final verification run and say so.
- Commit titles are Conventional Commits; no tool or assistant names.

## Review Focus

1. **Corrupt or missing snapshot file** (first install, App Group missing): the widget shows "Set up Mivu" and never crashes. Test in Task 1.
2. **Over target** (2,300 of 2,000): the text shows the real number, and the ring caps at full. Test in Task 1 (`ringFraction`).
3. **Profile switch or deleted profile**: the snapshot is rewritten for the new selection, and no selection means `hasDiary == false`. Test in Task 2.
4. **Time zone travel**: `rolloverAt` is computed in the active day's `timeZoneID`, not the device zone. Test in Task 1.
5. **Largest Dynamic Type in the small widget**: the figure scales down (`minimumScaleFactor`) instead of truncating. Previews are checked in Task 4.

### Task 1: Shared snapshot model

**Files:**
- Create: `ios/Shared/WidgetSnapshot.swift`
- Test: `ios/MivuTests/WidgetSnapshotTests.swift`
- Modify: `ios/Mivu.xcodeproj/project.pbxproj` (new synchronized root group `Shared`, member of `Mivu`; Task 4 adds the extension)

**Interfaces:**
- Produces:
  - `struct WidgetSnapshot: Codable, Equatable, Sendable { var day: String; var eaten: Double; var target: Double?; var hasDiary: Bool; var rolloverAt: Date; var writtenAt: Date }`
  - `static let appGroup = "group.com.yakov103.mivu"`
  - `static func fileURL(in container: URL) -> URL`: `container/widget-snapshot.json`
  - `static func read(from url: URL) -> WidgetSnapshot?`: nil on a missing or corrupt file
  - `func write(to url: URL) throws`: an atomic write
  - `static func nextRollover(after now: Date, timeZoneID: String, cutoffHour: Int) -> Date`
  - `func afterRollover() -> WidgetSnapshot`: the same snapshot with `eaten = 0`
  - `var ringFraction: Double`: `min(eaten / target, 1)`, or 0 without a target

- [ ] **Step 1: Write the failing tests**

```swift
@Suite struct WidgetSnapshotTests {
    let sample = WidgetSnapshot(day: "2026-10-20", eaten: 1359.6, target: 2000, hasDiary: true,
                                rolloverAt: Date(timeIntervalSince1970: 1_000), writtenAt: Date(timeIntervalSince1970: 0))
    @Test func roundTripsThroughFile() throws {
        let url = FileManager.default.temporaryDirectory.appending(path: UUID().uuidString + ".json")
        try sample.write(to: url)
        #expect(WidgetSnapshot.read(from: url) == sample)
    }
    @Test func missingOrCorruptFileReadsNil() throws {
        let url = FileManager.default.temporaryDirectory.appending(path: UUID().uuidString + ".json")
        #expect(WidgetSnapshot.read(from: url) == nil)
        try Data("{".utf8).write(to: url)
        #expect(WidgetSnapshot.read(from: url) == nil)
    }
    @Test func ringCapsWhenOverTargetAndIsEmptyWithoutTarget() {
        var s = sample; s.eaten = 2300
        #expect(s.ringFraction == 1)
        s.target = nil
        #expect(s.ringFraction == 0)
    }
    @Test func afterRolloverKeepsTargetAndZeroesEaten() {
        let next = sample.afterRollover()
        #expect(next.eaten == 0 && next.target == 2000 && next.hasDiary)
    }
    @Test func rolloverUsesTheDaysTimeZone() {
        // 2026-10-20 23:00 UTC is 02:00 on the 21st in Jerusalem; the next 4 AM there is 01:00 UTC on the 21st.
        let now = ISO8601DateFormatter().date(from: "2026-10-20T23:00:00Z")!
        let next = WidgetSnapshot.nextRollover(after: now, timeZoneID: "Asia/Jerusalem", cutoffHour: 4)
        #expect(next == ISO8601DateFormatter().date(from: "2026-10-21T01:00:00Z")!)
    }
}
```

**Interfaces:**
- Consumes: `WidgetSnapshot.read/fileURL/afterRollover/ringFraction/appGroup` (Task 1), `LogFoodIntent`, `OpenCoachIntent` (Task 3)
- `Widgets.xcconfig`: `#include "Shared.xcconfig"`, `PRODUCT_NAME = MivuWidgets`, `PRODUCT_BUNDLE_IDENTIFIER = com.yakov103.mivu.widgets`, `INFOPLIST_FILE = Config/Widgets-Info.plist`, `CODE_SIGN_ENTITLEMENTS = Config/MivuWidgets.entitlements`, `SWIFT_ACTIVE_COMPILATION_CONDITIONS = $(inherited) WIDGET_EXTENSION`, `SKIP_INSTALL = YES`, `APPLICATION_EXTENSION_API_ONLY = YES`
- `Widgets-Info.plist`: `NSExtension` → `NSExtensionPointIdentifier = com.apple.widgetkit-extension`; `CFBundleDisplayName = Mivu`
- Provider: `timeline` returns `[entry(now, snapshot), entry(snapshot.rolloverAt, snapshot.afterRollover())]` with policy `.never`. A nil snapshot becomes a single "Set up Mivu" entry. The app's reload is the refresh trigger.

**Layout (exact spacing is the builder's call):**
- Small: Pip (top-leading, ~36 pt), ring with "1,360" over "of 2,000 kcal". Without a target: "1,360 kcal" over "Set a target". Without a diary: Pip plus "Set up Mivu".
- Medium: the small layout on the leading half; on the trailing half, two stacked `Button(intent:)` controls, "Log Food" (camera) and "Coach" (bubble.left.fill), each ≥ 44 pt tall.
- Circular: a `Gauge(value: ringFraction)` in `.accessoryCircularCapacity` style with the eaten number.
- Rectangular: "1,360 / 2,000 kcal" plus a linear gauge.
- `.minimumScaleFactor(0.6)` on numbers; `.accessibilityElement(children: .combine)` with the Global Constraints label.
